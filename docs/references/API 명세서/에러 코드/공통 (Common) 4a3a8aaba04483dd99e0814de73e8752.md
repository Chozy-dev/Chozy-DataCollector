# 공통 (Common)

| HTTP Status | Error Code | 설명 |
| --- | --- | --- |
| **400 Bad Request** | `C001` | **입력하신 정보가 올바르지 않습니다. 다시 확인해 주세요.**
요청 DTO의 유효성 검사(validation) 실패 시 발생합니다. |
| **409 Conflict** | `C002` | **이미 등록된 정보입니다. 다른 정보로 시도해 주세요.**
데이터베이스에 이미 존재하는 유니크한 값으로 등록을 시도할 때 발생합니다. |
| **404 Not Found** | `C003` | **요청하신 페이지나 기능을 찾을 수 없습니다.**
존재하지 않는 API 엔드포인트로 요청 시 발생합니다. |
| **500 Internal Server Error** | `C004` | **일시적인 서버 오류가 발생했습니다. 잠시 후 다시 시도해 주세요.**
처리되지 않은 예외가 서버 내부에서 발생했을 경우입니다. |
| **400 Bad Request** | `C005` | **입력 형식이 올바르지 않습니다. 올바른 형식으로 입력해 주세요.**
요청 파라미터의 타입이 일치하지 않을 때 발생합니다. (예: 숫자가 와야 할 곳에 문자열 입력) |
| **403 Forbidden** | `C006` | **해당 작업에 대한 권한이 없습니다.**
필요한 권한이 없는 사용자가 특정 리소스에 접근을 시도할 때 발생합니다. |
| **405 Method Not Allowed** | `C007` | **지원하지 않는 요청 방식입니다. 올바른 방식으로 다시 시도해 주세요.**
허용되지 않은 HTTP 메소드로 API를 호출했을 때 발생합니다. (예: GET만 허용되는 엔드포인트에 POST 요청) |
| **400 Bad Request** | `C008` | **필수 파라미터가 누락되었습니다. 요청을 확인해 주세요.**
API 요청에 필요한 필수 쿼리 파라미터가 누락되었을 때 발생합니다. |
| **400 Bad Request** | `C009` | **JSON 형식이 올바르지 않습니다. 요청 데이터를 확인해 주세요.**
요청 본문(body)의 JSON 데이터 형식이 잘못되었을 때 발생합니다. |
| **415 Unsupported Media Type** | `C010` | **지원하지 않는 미디어 타입입니다.**
서버가 지원하지 않는 `Content-Type`으로 요청했을 때 발생합니다. |
| **400 Bad Request** | `C011` | **파일 크기가 허용된 범위를 초과했습니다.**
업로드하는 파일의 크기가 서버에서 설정한 최대 크기를 초과했을 경우 발생합니다. |
| **408 Request Timeout** | `C012` | **요청 시간이 초과되었습니다. 다시 시도해 주세요.**
서버의 비동기 요청 처리 시간이 초과되었을 때 발생합니다. |
