# 인증 (Auth)

| HTTP Status | Error Code | 설명 |
| --- | --- | --- |
| **401 Unauthorized** | `A003` | **로그인이 만료되었습니다. 다시 로그인해 주세요.**
Access Token이 만료되었을 때 발생합니다. |
| **401 Unauthorized** | `A004` | **인증 정보가 올바르지 않습니다. 다시 로그인해 주세요.**
유효하지 않은 토큰(서명 오류, 형식 오류 등)으로 요청했을 때 발생합니다. |
| **401 Unauthorized** | `A005` | **로그인 세션이 만료되었습니다. 다시 로그인해 주세요.**
Refresh Token이 만료되었을 때 발생합니다. |
| **400 Bad Request** | `A006` | **인증번호가 올바르지 않거나 만료되었습니다. 다시 확인해 주세요.**
SMS 인증번호가 틀렸거나 유효 시간이 초과되었을 경우 발생합니다. |
